# @quran/web

TanStack Start (Vite + Nitro) app — the PWA + (Phase 5) Capacitor shell.

## Routes (Phase 0)

| Path | Purpose |
|---|---|
| `/` | auth gate → `/login` or `/app` |
| `/login` | email/password (full screen ported in Phase 3) |
| `/_protected/app` | placeholder home (role-split into student/teacher tabs in Phase 3) |
| `/api/auth/$` | better-auth handler (sign-up/in/out, sessions) |
| `/api/cron/daily` | Vercel Cron daily scheduler (body filled in Phase 4) |

## Push (Web Push / VAPID)

- `src/server/subscribe-push.ts` — stores a browser subscription in `push_tokens`
- `src/server/push.ts` — `sendPush(userId, msg)` fan-out
- `public/sw.js` — receives `push` events, shows notifications

Generate keys once: `npx web-push generate-vapid-keys` → set `VAPID_*` in `.env`.
